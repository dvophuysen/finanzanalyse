# Kategorien-Katalog (V3)

Zwei Hierarchie-Ebenen: **Hauptkategorie → Unterkategorie**.
Pro Buchung: 1 Hauptkategorie, 1 Unterkategorie, 0..n Tags (siehe `tags.md`).

Quellen: angelehnt an „Geld & Haushalt"-Ratgeber + DGH-Kontenplan, mit
Schärfungen für unsere Beratungs-/Auswertungs-Ziele.

## Hinweise

- **„Sonstiges/Sonstiger" als Unterkategorie ist immer Hinweis auf** Schwäche
  der Hierarchie oder seltenen Sonderfall. Bei mehrfachem Auftreten gleicher
  Posten unter „Sonstiges" → eigene Unterkategorie ergänzen.
- **Splits**: ein Vertrag (z. B. Miete + Nebenkostenpauschale) kann in mehrere
  Buchungen mit unterschiedlichen Unterkategorien aufgeteilt werden.
- **Tags** ergänzen die Hierarchie um orthogonale Dimensionen
  (Person, Bedarf, Steuer, Cashflow-Typ, Lifecycle, …) – siehe `tags.md`.
